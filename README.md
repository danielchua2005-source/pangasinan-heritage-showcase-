# Pangasinan Heritage Digital Showcase

Next.js 14 App Router implementation for Activity 1.1.

## Atomic Design structure

- Atoms: Button, Typography, Color Tokens, Icon, Image
- Molecules: Heritage Card, Search Form, Navigation Item
- Organisms: Heritage Grid, Header Navigation, Hero

## Included pages

- `/` — homepage and featured heritage grid
- `/heritage` — heritage directory
- `/about` — project overview and architecture goals

The project uses reusable React components, responsive CSS, semantic HTML, keyboard focus states, and a mobile-first layout.

## Run

Install dependencies, then run the development server with `npm run dev`.
