# Atomic Design Component Reference

## Atoms

### Button
Reusable primary/secondary action button. It adapts through flexible padding and wraps naturally on small screens.

### Typography
Reusable heading/description block for page introductions.

### Color Tokens
Documents the project's primary visual tokens.

### Icon
Small text-based icon abstraction for arrow, search, and map symbols.

### Image
Reusable visual wrapper with descriptive accessible labeling.

## Molecules

### Heritage Card
Used for a tourism/heritage site preview inside the responsive heritage grid. On desktop the grid uses three columns, two on tablet, and one on mobile.

### Search Form
Used in the hero area to provide a lightweight search interaction. The form remains horizontally compact and adapts to small screens.

### Navigation Item
Reusable link unit used by the header navigation.

## Organisms

### Heritage Grid
Combines multiple Heritage Cards into a responsive collection.

### Header Navigation
Combines branding and Navigation Items into the primary site navigation.

### Hero
Combines Typography, Buttons, and Search Form into the homepage introduction.
